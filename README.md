# Breakpoint Live Philadelphia Slide Decks

This repository collects slide decks for Breakpoint Live Philadelphia.

Open `index.html` for the GitHub Pages landing page.

## Structure

- `index.html` links to all published slide decks.
- `decks/` contains source slide decks.
- `decks/logging-the-right-way/` contains the "Logging the Right Way" deck.
- `outputs/` is reserved for generated exports such as PDFs, screenshots, and deployment bundles.

Each deck should live in its own folder with an `index.html` entry point.
