object, JSON, record04 / 19
console is not one format

Console can log objects. JSON is text. Telemetry is a record.

Devtools inspection is not the same as structured telemetry.

object / reference
console.log(user)

// expandable object
// runtime view
// not a field contract

Useful while debugging. Devtools can inspect actual objects or references, and behavior varies by runtime.

JSON text
console.log(JSON.stringify({
  userId,
  orderId,
  latencyMs
}))

More portable than an object dump, but still just text unless the pipeline parses and indexes the fields.

telemetry record
logger.info("checkout.completed", {
  userId: user.id,
  orderId: cart.orderId,
  latencyMs,
  status: response.status
})

A named event with known keys. Sentry can filter it, correlate it, and keep it attached to the trace.

choose the boundary07 / 19
field boundary beats object dump

telemetry should stop at the facts you choose.

Objects are runtime graphs. Logs are contracts. Pick scalar fields and leave traversal out of the pipeline.

unbounded graph
const cart = { id: "cart_9" }
cart.self = cart

console.log(cart)
// inspectable in devtools

JSON.stringify(cart)
// TypeError: circular structure
The runtime object can contain cycles, references, and accidental private detail.
chosen field boundary
logger.info("cart.checked_out", {
  cartId: cart.id,
  userId: user.id,
  totalCents,
  itemCount
})
// no graph traversal
The logger reads four facts and stops. The boundary is intentional.
